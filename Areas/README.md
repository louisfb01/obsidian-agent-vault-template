# Areas

Your real life and work notes, the human side of the vault. Each area has a hub note named after its folder, and each multi-session piece of work gets its own project folder inside an area ([[AGENT-RULES]] §3). Rename these to fit you.

```
Areas/
  Personal/
    Personal.md        # hub (private by default)
  Professional/
    Professional.md    # hub
    example-project/   # the project folder pattern: index.md + progress-log.md
```

Add your own top-level areas (a partner, a company, a side project), then add a row for each in the `AGENT-RULES.md` §1 folder map. Skills read facts from here and must never invent what isn't written.
