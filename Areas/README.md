# Areas

Your real life and work notes — the human side of the vault. Skills read from here
for grounding and write finished deliverables back here. Rename these to fit you.

```
Areas/
  Personal/       # health, reflection, personal projects
  Professional/   # projects, meetings, and finished deliverables from skills
```

Add your own top-level areas (a partner, a company, a side project). Skills pull
facts from here but must never invent what isn't written.
